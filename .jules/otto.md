# Otto's Journal — Reusable Backlog Management Knowledge

## 2026-09-13 - Active Specialist PRs and Backlog Reconciliation **Learning:** Active implementation PRs from specialist agents (e.g., Marty, Kira) or Dependabot represent work in flight and should be protected rather than restructured underneath active implementation. **Action:** Always cross-reference open PRs against open issues; preserve active implementation tickets while ensuring completed PRs are verified against repository source code before closing or updating backlog items.
