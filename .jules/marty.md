## 2026-09-02 - DRF Error Format Extraction **Learning:** Django REST Framework API error responses vary between `{ error }`, `{ detail }`, string arrays, and field validation dicts like `{ field: ['message'] }`. **Action:** Use `getResponseErrorMessage` from `authSession.js` and `safeReadJson` across frontend components and services rather than duplicating local `responseError` functions or calling raw `response.json()` without error guards.
