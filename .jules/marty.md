## 2026-08-31 - Auth session error formatting and stale profile cleanup **Learning:** `persistAuthSession` in `frontend/src/services/authSession.js` previously ignored missing/falsy profile fields, allowing stale `username` and `email` session storage values from a previous session to persist if the new login or registration payload omitted them. Additionally, auth components were duplicating network error detection logic (`isNetworkError`). **Action:** Always clear stale profile keys when new auth payloads omit profile attributes, and use `formatAuthErrorMessage` in `authSession.js` for consistent auth error presentation.
