## 2026-08-31 - Batch Catalog Version Lookups **Learning:** When validating or materializing nested meal item trees, looking up individual catalog versions produces N+1 DB queries. Batch-querying versions via `pk__in` with prefetching eliminates query proliferation. **Action:** Reuse `_visible_catalog_versions_map` or pass pre-fetched catalog maps when validating or saving meal item trees.
