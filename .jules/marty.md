## 2026-08-31 - Safe Temporary Proposal Deletion in Meal Adjustments **Learning:** Meal adjustment endpoints create temporary `MealProposal` database records to process follow-up calculation. If follow-up calculation or response serialization raises validation or runtime errors, proposals will leak as orphan records unless cleaned up in `finally` or `except Exception` blocks. **Action:** Future runs touching proposal/draft adjustment workflows should wrap temporary proposal instances in `try...finally` deletion blocks.
